# Конструктор иллюстраций

Веб-сервис, который собирает композиции из готовых векторных объектов библиотеки. Новые объекты он не создаёт: в итоговый SVG попадают только контуры двадцати исходных иллюстраций (10 объектов в главном и фоновом состоянии), скопированные без изменений.

- **Сервис:** https://hqvdvn-cmd.github.io/figma_compositor/
- **Демонстрация (1 минута):** https://hqvdvn-cmd.github.io/figma_compositor/demo.mp4
- **Примеры композиций:** папка [`examples/`](examples)

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # сервис на http://localhost:5173
npm test           # тесты модели
npm run build      # статическая сборка в dist/
```

`dist/` — обычная статика без серверной части, её можно выложить на любой хостинг.

## Что умеет

**Два сценария сборки**

- *По смыслу.* Человек вводит метафору или заголовок, сервис выбирает подходящие объекты и показывает, по каким словам сделан выбор. «Как копить деньги на обучение» даёт монету и книгу.
- *По названиям.* Человек перечисляет объекты: «лампа, наушники, телефон». Слова, которых нет в библиотеке, сервис называет отдельно.

В обоих случаях объекты раскладываются автоматически в одном из трёх режимов: по центру, сбоку, под заголовок. Кнопка «Другой вариант» пересобирает раскладку с теми же объектами.

**Ручная работа с холстом**

- добавить объект из библиотеки главным или фоновым;
- перетащить, повернуть (ручка над рамкой, с Shift шаг 15°), дублировать, удалить;
- поменять порядок слоёв и состояние объекта;
- отменить и вернуть действие.

Клавиши: стрелки двигают на 1 единицу (с Shift на 10), `[` и `]` меняют слой, `Ctrl+D` дублирует, `Delete` удаляет, `Ctrl+Z` и `Ctrl+Shift+Z` — история.

**Формат и размер.** Три формата из примеров библиотеки: 1000×1000, 1200×630, 800×1200. Размер L подгружает детальные объекты, S — упрощённые; холст S вдвое меньше. Положения объектов хранятся в единицах L, поэтому размер переключается без пересборки.

**Палитра.** Три схемы из Figma встроены. Свою можно загрузить файлом, композиция перекрасится сразу. Кнопка «Образец» скачивает текущую схему в том же формате.

```json
{
  "name": "Лесная",
  "background": ["#DDEBD0", "#A9CF8E", "#4F8A4B"],
  "objects": ["#FFE08A", "#FF8F6B", "#FFD9C7"],
  "ink": "#181817",
  "paper": "#FFFFFF"
}
```

Принимается также SVG-палитра в раскладке библиотеки: восемь прямоугольников, слева цвета фона, справа цвета объектов.

**Экспорт.** «Скачать SVG» отдаёт файл, где каждый объект — отдельная группа с понятным id (`lamp-main-2`), а внутри лежат исходные контуры. Растра, масок и фильтров нет.

В Figma файл открывается фреймом с группами: фон, декор и по группе на объект с его названием («Монета», «Телефон»). Первый клик выделяет фрейм целиком; чтобы добраться до объекта, сделайте двойной клик или раскройте фрейм в панели слоёв.

## Архитектура

```
source/figma/            SVG, выгруженные из Figma через Plugin API (exportAsync)
scripts/build-library.mjs  source/figma → src/library/data
scripts/build-masks.mjs    силуэты объектов для раскладки
scripts/make-examples.ts   примеры композиций
scripts/record-demo.mjs    запись демонстрации
src/library/data/        L.json, S.json, schemes.json, masks.json — данные библиотеки
src/model/               логика без интерфейса
  matcher.ts             текст → объекты
  composer.ts            объекты → раскладка по силуэтам
  palette.ts             схемы и разбор файла палитры
  render.ts              документ → SVG
src/ui/, src/App.tsx     интерфейс на React
examples/                примеры, собранные тем же кодом
```

### Хранение

Исходники лежат в `source/figma` в том виде, в каком их отдала Figma. Скрипт `npm run library` превращает их в JSON. Каждый объект хранится как список контуров `[слот, d]`: геометрия `d` переносится дословно, а hex-цвет заменяется номером слота палитры.

Слотов восемь, они повторяют палитру в Figma:

| Слот | Назначение | Сиреневая схема |
|---|---|---|
| 0–2 | цвета фона: светлый, средний, тёмный | `#D7CDF5` `#AA9BF0` `#7864D7` |
| 3 | контур | `#181817` |
| 4–6 | цвета объектов | `#F9ECB0` `#F9A3AA` `#FFE3E1` |
| 7 | бумага | `#FFFFFF` |

Во всех сорока исходных SVG встречаются только эти восемь цветов, поэтому замена однозначна. Скрипт останавливается с ошибкой, если встретит цвет вне палитры.

### Извлечение

Наборы L и S собираются в отдельные чанки и грузятся по требованию: открывший сервис человек скачивает только выбранный размер (около 220 КБ в gzip).

### Переиспользование

Объект на холсте — это ссылка на запись библиотеки плюс положение, поворот и состояние. Копирования геометрии нет: два телефона в композиции ссылаются на одну запись. Перекраска сводится к подстановке другой восьмёрки цветов при отрисовке, сами контуры не трогаются.

Правила библиотеки зашиты в модель, а не в интерфейс:

- у объекта нет масштаба, поэтому пропорции объектов между собой изменить нельзя;
- фон холста и декор берут только слоты фона, цвета объектов туда попасть не могут;
- фоновые объекты содержат только слоты 0–2, это проверяет тест.

### Подбор по смыслу

`matcher.ts` — словарь: для каждого объекта заданы основы слов с весами, всего около 880 основ на русском и английском. Запрос разбивается на слова, слово сравнивается с основами по началу (для коротких и двусмысленных слов — целиком), объекты ранжируются по сумме весов. Прямое название объекта весит больше любого смысла. Если совпадений нет, сервис так и пишет и ничего не подставляет.

Словарь выбран за то, что работает мгновенно, без ключей и сервера, и объясняет каждый выбор. Его слабое место — формулировки, которых в словаре нет. Интерфейс модуля узкий (текст на входе, ранжированный список на выходе), поэтому словарь можно заменить эмбеддинг-моделью, не меняя остальной код.

### Раскладка

`composer.ts` получает список объектов, размер холста, режим и зерно и подбирает положения перебором с оценкой.

Чтобы объекты стояли рядом, а не лежали друг на друге, раскладка знает их настоящую форму. Скрипт `build-masks.mjs` заранее строит для каждого объекта силуэт на сетке с шагом 25 единиц: клетка занята, если в неё попадает любая заливка объекта, включая его тень. В итоговый SVG силуэты не попадают.

Главное правило — объекты не накладываются. Ни главные друг на друга, ни фоновые под главные: соседей раскладка сравнивает по силуэтам, расширенным на клетку, поэтому между объектами остаётся зазор. Наложение стоит дороже всего остального, так что при нехватке места объект скорее уйдёт за край холста, чем ляжет на соседа.

Остальные штрафы в оценке:

- объект ушёл за край сильнее, чем требует его размер: мелкий обязан поместиться целиком, крупный (книга шире холста) может быть обрезан;
- объекты разошлись слишком далеко и перестали быть группой;
- соседние объекты стоят не вдоль изометрических осей;
- группа съехала от точки фокуса или зашла в зону заголовка;
- у лампы и вазы срезан верх.

Из случайных стартовых положений раскладка спускается к ближайшему минимуму и берёт лучший результат из нескольких попыток. Фоновый объект ставится вторым проходом и необязателен: если встать без наложения некуда, композиция собирается без него, а интерфейс об этом сообщает. Порядок слоёв — по изометрии: кто ниже на экране, тот ближе.

Масштаб не меняется: в примерах библиотеки объекты стоят в натуральную величину. Поэтому три крупных объекта на одном холсте обрезаются краями — иногда так, что от книги остаются одни страницы. Это правится руками или сменой формата. Одинаковое зерно даёт одинаковый результат, одна раскладка считается около 25 мс.

## Проверка

`npm test` запускает 18 тестов модели. Среди них:

- геометрия каждого контура в данных совпадает с выгрузкой из Figma посимвольно;
- в 45 автоматических раскладках ни один объект, включая фоновый, не накладывается на другой;
- словарь понимает десять разных формулировок и не путает похожие слова («подписка» и «подпись»);
- экспорт не содержит растра и сохраняет все контуры;
- смена схемы меняет в SVG только цвета;
- файл палитры с ошибкой даёт понятное сообщение.

## AI-инструменты

- Claude Code (Anthropic) — разбор задания, код сервиса, тесты, словарь смыслов.
- Figma Plugin API в браузере — выгрузка исходных SVG из файла задания.
- Chrome DevTools Protocol и ffmpeg — запись демонстрации (`scripts/record-demo.mjs`).

В самом сервисе AI не работает: подбор, раскладка и перекраска детерминированы.
